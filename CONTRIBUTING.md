# Contributing

This repository is a **read-only, auto-generated mirror** of Airwallex's
OpenAPI specification, synced from internal systems. Because everything here is
generated upstream, **we cannot accept pull requests** — any PR will be closed.

**Issues are welcome.** Spotted an inaccuracy in the spec, hit a bug in the API,
or want to request a change? Please
[open an issue](https://github.com/airwallex/openapi/issues) — we triage here
and work internally with the owning teams, and fixes flow back into the mirror
automatically.

For account-specific or urgent support, use the official Airwallex channels
linked from <https://www.airwallex.com/docs>.
